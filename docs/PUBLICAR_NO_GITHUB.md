# Publicação no GitHub Pages — Etapa 4

1. Descompacte o ZIP da Etapa 4.
2. Na raiz do repositório GitHub, envie **os arquivos e pastas internos** de `O_Tesouro_das_Palavras_Etapa4` (o `index.html` na raiz do repositório), substituindo a versão antiga.
3. Confira se as pastas `src/`, `styles/`, `data/` e `assets/` foram enviadas por inteiro. Se faltar algum arquivo, o jogo não inicializará.
4. Acesse **Settings → Pages → Build and deployment**. Selecione **Deploy from a branch**, branch `main` e pasta `/(root)` para esse modelo de publicação.
5. Abra o endereço fornecido pelo GitHub; use **Continuar** apenas se o navegador conservar o salvamento v4, ou **Nova Campanha** para começar de novo.
6. Verifique no computador e celular: **Mapa → Cavar → Ler questão → Errar → Acertar → Baú aberto → Continuar**.

**Direitos autorais:** antes de disponibilizar publicamente os conteúdos integrais da coletânea PAEBES, confirme as autorizações de distribuição e reprodução dos textos e imagens. O projeto contém reproduções de todos os itens solicitados e também o PDF original para auditoria.

**Dica:** se o GitHub Pages mostrar a versão anterior, limpe o cache da página ou abra em uma aba anônima e confira se o commit da Etapa 4 foi publicado.
